# 请不要删除这条帖子

中文校园 ARG 网页解谜游戏（试玩版，第一至第三幕，约 30–45 分钟）。玩家是 2026 年的陈默，在母校旧论坛关闭前的最后一小时，调查七年前好友林知夏的死亡，并第一次与 2019 年的自己通信。

所有学校、人物、网址均为虚构。不联网、无外部素材，图片全部为内嵌 SVG，音效为 WebAudio 合成。

## 启动

- 直接双击 `dist/index.html` 即可游玩（无需安装）。
- 或双击 `启动游戏.cmd`，或运行 `node server.cjs` 后访问 http://127.0.0.1:4173 。
- 在线版：https://sakura0000cai.github.io/keep-this-post/ （`gh-pages` 分支，需要把 `dist/` 同步过去）。

## 目录

```
dist/
  index.html          浏览器外壳（标签页、地址栏、任务栏）
  css/shell.css       外壳样式
  css/school.css      学校官网：2010 年前后院校门户，红色主调
  css/forum.css       榕园社区：2000 年代中文社区版式，红色主调
  js/core.js          存档、游戏内时间、音效、通用工具
  js/art.js           内嵌 SVG：横幅、合照、校园照片、广告、头像
  js/data-school.js   官网文章、班级名单
  js/data-forum.js    论坛用户、版块、帖子、心情、短消息
  js/school.js        官网页面
  js/forum.js         论坛页面与谜题判定
  js/story.js         跨时间回复、分层提示
  js/main.js          路由、地址栏、任务栏
```

无构建步骤：脚本按顺序以普通 `<script>` 加载，挂在全局 `G` 上，因此 `file://` 直接打开也能运行。

## 玩法

- 两个网站之间切换，可在地址栏手动输入网址。
- 线索自动记入任务栏“调查笔记”；“卡住了？”提供三级提示，最后一级给出答案。
- 进度保存在浏览器 localStorage；“重新开始”清除存档。

`制作说明与验收.md` 含完整谜底，首次试玩前请勿阅读。

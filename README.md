# 请不要删除这条帖子

可离线运行的中文校园 ARG 序章，预计 15–25 分钟。两套仿真网站、2019 / 2026 双时间线，从迁移通知开始，直到首次跨时间通信。无须任何真实账号或联网服务。

## 启动

- 最简方式：直接打开 `dist/index.html`。所有素材随项目提供，无需安装依赖。
- Windows：双击 `启动游戏.cmd`。有 Node.js 时启动本地服务；没有时直接打开网页。
- 推荐：在本项目文件夹打开终端，运行 `node server.cjs`，浏览器访问 http://127.0.0.1:4173 。按 Ctrl+C 停止。
- 端口被占用时，PowerShell 可运行 `$env:PORT=4174; node server.cjs`，然后访问新端口。

首次进入学校首页，阅读迁移公告即可开始。不需要开发者工具。右下角提供分层提示；调查笔记自动收集已经看过的线索。

## 存档

进度保存在当前浏览器的 localStorage，刷新不会丢失。无痕模式、文件模式或浏览器限制可能不保留存档，推荐本地服务方式。不同端口、浏览器和文件方式之间不共享存档。“重新开始”需再次确认后才清除。

## 项目

- `dist/index.html`：入口与网页存档外壳
- `dist/style.css`：旧学校官网 / 2010s BBS 视觉与移动端布局
- `dist/app.js`：剧情内容、内嵌 SVG 档案图、谜题、状态与存档
- `server.cjs`：只绑定本机的静态服务器
- `tests/smoke.cjs`：无依赖剧情回归检查，执行 `node tests/smoke.cjs`
- `制作说明与验收.md`：包含谜底和剧情逻辑；首次试玩前请勿阅读

这是纯前端纵切 Demo，跨时间通信为剧情模拟，无真实联网聊天；示例照片为矢量档案示意图。两站在同一网页内模拟独立域名和导航。最后一段仅确认过去收到消息，不宣称整段故事或营救已完成。人物、学校、域名与事件均为虚构。
